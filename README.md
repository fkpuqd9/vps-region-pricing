## 条款里的四笔隐性成本

下面几条来自第三方整理的官方条款要点，付款前建议在官网条款页再对一遍。

**退款是阶梯的，而且钱不进你的银行卡。** 新购 3 天内退 80%，3 到 7 天退 50%，7 到 10 天退 20%，超过 10 天不退。在控制面板删除服务器会自动退款，但退到账户余额，不原路退回，且余额只能继续买 Akile 的服务。想「买来试两天不满意就退」的人要算清楚，第一天的退款成本就是 20%，加上资金被锁在账户里。

**换 IP 要钱。** 控制面板的换 IP 功能 35 元一次，走工单是 1500 AK 币一次。所以收到机器先查 IP 归属地和纯净度，不满意趁退款期内处理，别等用得顺手了再换。

**流量跑完是限速，不是停机。** 超出套餐流量后限速 10Mbps，不额外扣费。英国套餐的测评里提到重置流量 14 元一次，其他地区是否同价需要下单页确认。

**买小了不能升配。** 这条最容易被忽略。Akile 的套餐不支持原地升级配置，觉得不够用只能重新买一台，旧的那台按退款规则处理。第一次买别抠那十元八元，内存从 1G 加到 2G 的差价，比重新买一台便宜得多。

优惠码方面，一个订单只能填一个码，码与码不能叠加，和特价套餐也不能叠加。网上流传一个轻量套餐 8 折码，整理页面的更新时间是 2026 年 1 月，能不能用在下单页试一次就知道，不用为了等码推迟购买。

## 线路名词怎么看：一张对应表

这是通用知识，不是 Akile 的官方标注，具体哪档走哪条线以官网为准。

AS4837 是联通普通线路，便宜、带宽给得足，晚高峰可能拥堵。AS9929 是联通精品线路，晚高峰稳定得多，价格只贵一点。CN2 GIA 是电信高端线路，三网回程都能沾光，延迟和稳定性第一梯队，价格也是第一梯队。CMIN2 偏移动用户，移动宽带访问延迟低。日本方向常见软银和 BGP 组合，亚太延迟比美西近不少。

对应的选择规则是：电信用户优先看 CN2 GIA，联通用户优先看 9929，移动用户优先看 CMIN2，预算紧就退一档选 9929 或 4837。
